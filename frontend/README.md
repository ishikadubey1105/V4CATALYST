# Frontend — PS3: Smart Patient Vital Monitoring & Clinical Dashboard

Owner: Ishika Dubey

Frontend for the ICU vital monitoring system: nurses record vitals electronically,
get reminders for scheduled observations, and doctors see a real-time dashboard
with patient status, trends and alerts.

## Planned stack
- React + Vite (TypeScript)
- Tailwind CSS
- React Router (role-based routes: nurse / doctor / admin)
- Recharts (vital trend charts)
- Axios (REST API calls to the backend)

## Planned screens
1. Login (role-based)
2. Nurse: patient list, vitals entry form (with validation), observation reminders
3. Doctor: ICU dashboard (bed grid with status), patient detail with vital trends, alerts panel
4. Digital ICU chart / report view (printable / export)
5. Audit trail view (admin)
